# SignalRGB Pro Switcher Free

Easily switch between your SignalRGB effects, presets, and layouts. Assign default layouts to effects, set favorites, ignore effects/presets/layouts, customize orders, and auto-cycle between them in various ways. 

## Requirement

- [AutoHotkey v2](https://www.autohotkey.com/)

## Features

- Full config editor GUI, manage your inventory & customize the tool in many ways
- Easily apply effects, presets, or layouts from your inventory
- Effect and preset auto-cycling (set a custom order or use random)
- Configureable hotkeys for everything
- AHK Tray menu to quick-access everything
- Assign layout to effects 
- Set favorites
- Ignore effects, presets, & layouts
